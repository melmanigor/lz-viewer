# לוז התקנות שבועי מ-Outlook

הסקריפט מוצא ב-Outlook את המייל האחרון עם קובץ **תכנית התקנות** ואת המייל האחרון של ברינקס עם הנושא **סריאלים לכספות**. הוא מצליב בין השניים ופותח בדפדפן לוז שבועי: רק התקנה והחלפה, עם הסריאל מברינקס לכל כספת, ופערים מסומנים בכתום. אפשר לסמן בדף גם הזזה.

## התקנה (פעם אחת, במחשב Windows שבו Outlook מותקן ומחובר לחשבון של העבודה)

```
pip install pywin32 openpyxl
```

שמרו את שלושת הקבצים באותה תיקייה: `sync_schedule.py`, ‏`schedule_template.html`, ‏`run.bat`.

## הרצה

לחיצה כפולה על `run.bat`, או:

```
python sync_schedule.py
```

ה-Outlook צריך להיות פתוח. הלוז נשמר בתיקייה `מסמכים\לוז התקנות` ונפתח אוטומטית בדפדפן.

## אם הטבלה של ברינקס מגיעה כתמונה

אם הטבלה במייל היא טבלה רגילה, הסקריפט קורא אותה ישירות. אם היא תמונה, צריך מפתח API של Claude:

```
setx ANTHROPIC_API_KEY "sk-ant-..."
```

בלי מפתח, הלוז נבנה מהאקסל בלבד, ואת התמונה אפשר לגרור לאפליקציה ב-claude.ai.

## הגדרות

בראש `sync_schedule.py`: כמה ימים אחורה לחפש, באילו תיקיות, מילות החיפוש בשם הקובץ ובנושא, והשולח.

## בדיקה בלי Outlook

```
python sync_schedule.py --plan "19112026 תכנית התקנות.xlsx" --email-image צילום.jpg
```

## מייל פערים לברינקס

אם נמצא פער במספר כספת (שני המספרים קיימים ושונים) או ביום (התקנה, החלפה או הזזה), הסקריפט שואל בחלון השחור אם להכין מייל לאריאל ולאוניד (Ariel.Zakuta@brinksinc.com, ‏Leonid.Rubinshtein@brinksinc.com).
אם עונים "כ", נפתח ב-Outlook מייל מוכן עם טבלת הפערים לפי התכנית, כולל החתימה שלך. **המייל לא נשלח לבד:** אפשר לערוך אותו וללחוץ "שלח", או לסגור בלי לשלוח.
הנמען וסוגי המשימות שנבדקים מוגדרים בראש `sync_schedule.py` (`GAPS_EMAIL_TO`, `GAPS_TASKS`).

## כשהתכנית מגיעה כמה פעמים

- הסקריפט עובר על המיילים מהימים האחרונים ובוחר את **המייל האחרון שהתקבל** עם קובץ "תכנית התקנות". אותו דבר לגבי המייל של ברינקס. גרסאות ישנות יותר ושרשורי RE/FW לא משפיעים.
- הוא זוכר מה בנה בפעם הקודמת. אם הקובץ והמייל של ברינקס לא השתנו, הוא לא בונה את הלוז מחדש ולא שואל שוב על מייל פערים. הוא רק פותח את הלוז הקיים.
- כשמגיעה גרסה חדשה של התכנית, הלוז נבנה מחדש לפיה.
- כדי לבנות מחדש בכל מקרה: `python sync_schedule.py --force`

## תשובות של ברינקס למייל הפערים

בכל הרצה הסקריפט בודק אם אריאל או לאוניד ענו למייל "פערים בסריאלים לכספות". אם הגיעה תשובה חדשה:
1. הוא מציג את הטקסט של התשובה, בלי הציטוט של המייל המקורי.
2. Claude מבין ממנה מה הם מבקשים לשנות: יום, מספר כספת או סריאל (צריך `ANTHROPIC_API_KEY`).
3. על כל שינוי הסקריפט שואל אותך "לשנות? (כ/ל)". **שום דבר לא משתנה בלי אישור שלך.** אם אתה עונה "ל", האקסל נשאר הקובע.
4. שינויים שאישרת נשמרים בקובץ `approved_changes.json` בתיקיית הלוז, ובכרטיס בלוז מופיעה התגית "עודכן לפי תשובת ברינקס". כדי לבטל שינוי, מוחקים אותו מהקובץ.

כל תשובה נבדקת פעם אחת בלבד.

## הקישור לטכנאי השני

אחרי כל ריצה הסקריפט מעלה את הלוז ל-Supabase (הפרויקט safeconfig, בחינם). הטכנאי השני פותח קישור קבוע בטלפון, נכנס פעם אחת עם שם משתמש וסיסמה, ורואה הכול כמו אצלך: הלוז, הפערים והסטטוסים. יש לו גם כפתור "הכן מייל פערים לברינקס", שפותח מייל מוכן באפליקציית המייל שלו, והוא לוחץ "שלח" בעצמו.
- `viewer_config.json` מכיל את קוד האדמין שמאפשר לעדכן את הלוז. **הוא נשאר רק אצלך ולא משתפים אותו.**
- שם המשתמש והסיסמה של הטכנאי נשמרים מוצפנים ב-Supabase. אפשר להוסיף משתמשים או להחליף סיסמה דרך Claude.
- הוספה למסך הבית: לפתוח את הקישור ב-Chrome או ב-Safari, ואז "הוסף למסך הבית".

## התראות

- כשנמצאים פערים, או כשברינקס ענו למייל הפערים, קופצת התראה בפינת המסך של Windows.
- **בדיקה אוטומטית ברקע (מומלץ):** לחיצה כפולה על `auto_check_install.bat` (פעם אחת). מאז Windows בודק את Outlook כל חצי שעה בין 07:00 ל-19:00, בלי חלון. כשיש פער או תשובה הוא מקפיץ התראה, ואז מריצים את `run.bat` כדי לאשר. אם לא השתנה כלום, לא תקבל התראה.
- להסרה: `schtasks /Delete /TN "LZ Install Schedule" /F`
- כל מה שקרה נרשם בקובץ `log.txt` בתיקיית הלוז.

## אם הסקריפט לא מצא את המיילים: העלאה ידנית
**במחשב:** גרור על `upload_manual.bat` את קובץ התכנית (xlsx) ו/או את צילום המייל של ברינקס (png/jpg) או את המייל ששמרת מ-Outlook כ-HTML (קובץ > שמירה בשם > HTML).
מה שלא גררת נמשך מ-Outlook כרגיל. הלוז נבנה, מתעדכן אצל הטכנאי ונשמר בארכיון, ואם יש פערים הוא מציע מייל פערים כרגיל (לא נשלח בלי אישור).

**בדף הצפייה (שניכם):** אחרי הכניסה יש למעלה שני מקומות:
- "תכנית התקנות": בחר את קובץ האקסל.
- "טבלת הסריאלים מברינקס": סמן את הטבלה במייל, העתק, לחץ על המסגרת והדבק. (תמונה אי אפשר לקרוא בדף בחינם; תמונה מעלים דרך upload_manual.bat.)
אפשר להעלות רק אחד מהם, והשני נשאר כמו שהיה. אחרי ההעלאה מופיע הכפתור "פרסם לשנינו", ורק אחריו השינוי עובר לשני ונשמר בארכיון.

## ארכיון שבועות
כל לוז שמתפרסם (מהסקריפט או מהדף) נשמר לפי שבוע. בתחתית הדף: רשימת השבועות, וחיפוש לפי שם אתר, מספר כספת או סריאל. לחיצה על "לשבוע" פותחת את אותו שבוע, ו"חזרה ללוז הנוכחי" מחזירה.
